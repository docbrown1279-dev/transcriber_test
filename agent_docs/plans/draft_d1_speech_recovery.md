# D1 follow-up — крутка Silero VAD (черновик, утверждение)

**Статус:** APPROVED — ветка `cursor/d1-silero-tune`; rescue 4–5 + regression 4–5 окон.  
**Триггер:** `eval/d1/3/transcript_diff.md` — много `missing_hyp`; сверка с `results/d1/` → почти всё **VAD_HOLE** (Silero не отдал речь).  
**Скоуп этого плана:** только настройки **Silero**. Не ASR-движок, не TEN/FSMN в этом прогоне, не full-meeting re-run.  
**Fallback later:** TEN ок для демо; для коммерции — **FSMN** (см. `docs/research_results/research_plan.md`). Сейчас hole-fallback в коде не подключён.

---

## 1. Ответ про «три библиотеки»

В **1f2** сравнивали **три VAD**, не один TEN:

| id | Что | Итог для стека |
|---|---|---|
| `silero` | основной ONNX | **основной** в демке |
| `ten_vad` | TEN-framework | выбран **только как fallback в дырах** Silero (лицензия Agora non-compete) |
| `fsmn_vad` | FunASR FSMN ONNX | хвост ловит слабее TEN, RAM больше → **не в стеке** |

Плюс отдельно три **эмбеддера** (WeSpeaker / ERes2Net / TitaNet) — к дырам речи не относятся.

Цитата из [`docs/research_results/reports/1f2/conclusions.md`](../../docs/research_results/reports/1f2/conclusions.md):

> Пороги VAD в 1f2 **не крутили** (TEN `threshold=0.5`). Имеет смысл только постобработка как у Silero (`min_speech` ~200 мс)…

То есть оптимальные пороги Silero **не подбирались** — взяли дефолты. Имеет смысл сначала выжать Silero настройками, и только если дыры останутся — вернуться к fallback (TEN или FSMN) отдельным решением.

## 3. План эксперимента (только Silero)

### 3.1 Цель

На тех же eval-клипах: **увеличить покрытие** интервалов, где в gold есть речь, а в attempt 3 — hole; при этом **не размывать** куски, где attempt 3 уже был human-good.

Критерий «успех настройки» на этапе VAD (ещё до полного ASR):

1. Rescue-окно: speech IoU / секунды перекрытия с gold-речью заметно выросли vs baseline (B0).
2. Если VAD покрыл — быстрый GigaAM на **этом** extract’е: есть ли осмысленный текст (опорные слова gold).
3. Regression-окно: покрытие и текст не хуже B0 (нет потери сегмента / сильного мусора).

### 3.2 Наборы окон (короткие куски, не вся встреча)

Аудио: `eval/d1/voice/<clip>/` или abs-вырезка из нормализованного WAV attempt 3.

**Rescue** (gold есть, hyp missing / VAD_HOLE):

| clip | clip-local (приоритет) | зачем |
|---|---|---|
| `test_voice` | 0–13; **22–64** | длинная дыра ~42 с |
| `test_apartments` | 0–5; **26–53** | серия missing SPEAKER_B |
| `test_transformers` | **33–85** | почти сплошная дыра |
| `test_ninth` | 1.2–3.6 | короткий missing |

**Regression** (human-good в attempt 3 — трогать только если rescue дал прирост):

| clip | clip-local |
|---|---|
| `test_apartments` | 5.57–14.46; 71–79 |
| `test_ninth` | 19.7–22.3; 40–63 |

Порядок: сначала **все rescue × варианты VAD**; если хоть один вариант даёт прирост покрытия — **тем же вариантом** прогнать regression. Не гонять regression на заведомо провальных сетках.

### 3.3 Варианты настроек (узкая сетка)

Baseline = текущий demo:

- **B0:** `threshold=0.5`, `neg=0.35`, `min_speech=200`, `min_silence=200`

Чувствительнее вход / мягче выход (гипотеза: тихие дальники):

| id | threshold | neg_threshold | min_speech_ms | min_silence_ms | идея |
|---|---:|---:|---:|---:|---|
| B1 | 0.35 | 0.20 | 200 | 200 | ниже порог входа |
| B2 | 0.25 | 0.15 | 200 | 200 | ещё агрессивнее |
| B3 | 0.35 | 0.20 | **100** | 200 | короче min speech |
| B4 | 0.35 | 0.20 | 200 | **100** | меньше рвёт на паузах |
| B5 | 0.35 | 0.20 | 100 | 100 | B3+B4 вместе |

Не больше **B0 + 3–4** живых прогона за итерацию: начать с **B0, B1, B2**; B3–B5 только если B1/B2 почти закрыли дыру, но режут фразы.

**Вне скоупа этого утверждения:** TEN/FSMN, смена ASR, whole-file gain/limiter, полный 25‑мин прогон. (Gain-баг с peak — отдельная заметка, не блокер для VAD-сетки на уже нормализованных клипах.)

### 3.4 Что мерить

На каждом окне × варианте:

| Метрика | Как |
|---|---|
| `speech_sec` / overlap с gold-интервалами | из регионов Silero |
| `new_cover` | секунды gold-речи, которые B0 не крыл, а вариант крыл |
| `false_extra` | грубо: речь VAD вне gold±0.5 с (не раздувать шум) |
| ASR smoke (только если `new_cover` > ~1 с) | GigaAM на новых регионах; 3–5 опорных слов vs gold |

Запись: `eval/d1/4/silero_tune.md` + таблица clip × variant → `rescue+` / `same` / `worse`.

### 3.5 Критерий «настройки годны → можно править demo»

- Хотя бы на **двух** rescue-клипах (`test_voice` 22–64 и один из apartments/transformers) появляется устойчивое покрытие дыр + читаемый ASR-текст.
- Regression human-good: без потери ранее хороших сегментов.
- Тогда — Phase B: вынести пороги в `config/demo.yaml`, зафиксировать выбранные значения, короткий регресс на 4 voice-клипах.

Если Silero даже на B2 **не** закрывает длинные дыры (как хвост 75–83 в 1f2) — стоп по крутке; отдельным планом fallback в holes: **TEN** (демо) или **FSMN** (коммерция / без Agora).

## 4. Ветка: main vs отдельная

**Факт по коду/тестам сейчас**

- Пороги Silero (`threshold` / `neg_threshold` / `min_silence_ms`) **захардкожены** в `silero.py`; в YAML только `min_speech_ms` + `fallback: disabled`.
- Существующие тесты **не** крутят сетку: `test_run_short_clip` — один прогон пайплайна; unit’ов на пороги VAD нет.
- На `main` сейчас только незакоммиченный план (+ правка `research_plan.md`).

**Рекомендация**

| Путь | Когда | Что делать |
|---|---|---|
| Остаться на текущей линии / маленький PR в main | Уже известны 2–3 числа и достаточно: вынести в `VadConfig` + поменять `demo.yaml` + 1–2 unit-теста на чтение конфига | Без grid-скриптов и без `eval/d1/4/` |
| **Отдельная ветка** (предпочтительно для этого A/B) | Нужен runner сетки B0–B2, заметки `eval/d1/4/`, сравнение rescue/regression | Закоммитить план+research_plan на main (или в PR), ветка `cursor/d1-silero-tune` от main, эксперимент там; в demo смержить только выбранные пороги |

Итого: **этот тюнинг — отдельная ветка.** Существующими тестами «просто подкрутить» нельзя: ручек в конфиге нет, сетки в pytest нет. После выбора чисел — тонкий PR (config + silero reads cfg), без скриптов тюна в продукте.
