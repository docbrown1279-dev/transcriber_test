## Зачем

Скользящие окна WeSpeaker с overlap дороги и могут смешивать голоса на стыках.  
Идея: **дешёвый черновик по VAD** → при необходимости **точный WeSpeaker**.

Уточнение терминов для агента:

| фраза | смысл в этом этапе |
|---|---|
| «спектральный анализ» | **дешёвые** признаки (MFCC / spectral flux / energy+F0), **без** WeSpeaker |
| «spectral clustering» | кластеризация по affinity-матрице (может быть на дешёвых фичах **или** на WeSpeaker) — не путать с FFT |

---

## Этап 1 — черновик (VAD-куски)

### Препроцесс островов

1. Silero VAD → speech regions → islands (как в проде, `vad_premerge_gap_sec`).
2. **Мелкие &lt; 1.0 с:**
   - если есть предыдущий остров — **приклеить к предыдущему**;
   - если подряд несколько &lt;1 с без крупного соседа — **склеить их в один** блок;
   - ведущий мелкий в начале файла — приклеить к следующему.
3. На выходе: список `units` (start, end), без deep embed.

### Варианты решения «тот же / другой спикер» и нарезки

| id | Метод |
|---|---|
| **1A** | На каждый `unit` — **один** WeSpeaker embed → решение по **смежным** переходам (cosine): склеить / оставить границу |
| **1B** | Смежные переходы по **дешёвому** спектральному расстоянию (MFCC/flux и т.п.), без WeSpeaker |
| **1C** | Дешёвые фичи по всем `units` (+ внутри длинных units change-point / spectral clustering) — **может нарезать** unit дальше |

Метрики этапа 1: wall, `n_units` до/после glue, `n_embed_calls` (для 1A), число границ, timelines. Качество — timelines для локального gold (clip01–03, apartments, ninth).

## Этап 2 — чистовик (WeSpeaker по записи)

На тех же wav, **после** VAD (можно стартовать от сырых islands или от units этапа 1 — зафиксировать в отчёте: baseline = current prod islands).

| id | Метод |
|---|---|
| **2A** | Как сейчас: `window=1.5`, `step=0.75` (**50% overlap**) → AHC 0.85 |
| **2B** | **Без overlap**: `window=step=1.5` (или эквивалент non-overlapping tiles внутри islands) → AHC 0.85 |
| **2C** *(добавка)* | **Один WeSpeaker на VAD-unit** (после glue &lt;1 с), без скользящего окна → AHC/spectral на этих векторах |

2C — мост между этапами и главный кандидат на скорость+чистоту стыков.
