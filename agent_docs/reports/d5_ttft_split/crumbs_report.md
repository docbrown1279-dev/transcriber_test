## Выводы

1. Крошки part02 у shared и unified **в основном в тех же местах** (сильное пересечение mid±0.4s); unified почти не сдвинул географию.
2. Большинство крошек split **не** совпадают с крошками full — это нарезка длинных full-turn’ов, не «те же короткие реплики».
3. Текст: unified ближе к full по LCS, чем shared; костыль &lt;1s уменьшит число turns, но ASR-мусор на крошках («звали») уже в тексте — склейка turns после ASR не починит слова, только границы/спикеров.
4. Единый diarize отложен по TTFT; пересборка центроидов — следующий рычаг после фикса громкости.
