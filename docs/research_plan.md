# Этап 1b — связный текст с диаризацией

Общая картина пайплайна уже есть (medium ASR, ffmpeg-шумодав вреден, чанкинг/саммари пока сырые). **Сейчас не продолжаем полный конвейер.** Цель этого этапа: получить **внятный осмысленный текст совещания с привязкой спикеров**.

Критерий успеха: **связный смысл**, а не `% русских слов ≥ 0.9`. Словарная метрика — только вспомогательная.

## Доступ Hugging Face (обязательный стоп)

Перед установкой WhisperX/pyannote агент проверяет токен и скачивание gated-файлов (`speaker-diarization-3.1`, `segmentation-3.0`, `speaker-diarization-community-1`).  
**401/403 или нет токена → остановить прогон**, записать отчёт, не продолжать ASR. Дальше разбирает человек.

## Конвейер

`нормализация громкости → Whisper large + диаризация → проверка смысла (Qwen3-8B)`  
при плохом смысле → **нейросетевой** шумодав (не ffmpeg) → повтор ASR/диаризации  
если один спикер явно хуже → доп. обработка **только его** сегментов

## Порядок попыток (закрытый список)

Нельзя изобретать ветки вне списка. Ошибка runtime (crash, OOM, пустой вывод) → retry той же конфигурации (макс. 2 retry). Плохой смысл → следующий пункт списка, не бесконечный тюнинг.

### A. Стек ASR + диаризация (макс. 3 варианта)

1. **WhisperX `large-v3` + loudnorm** (без компрессии динамического диапазона).
2. Если WhisperX не ставится / не запускается → **faster-whisper `large-v3` + pyannote отдельно** на том же loudnorm-аудио. Нужен `HF_TOKEN` (gated pyannote).
3. Если `large-v3` не тянет CPU/RAM (OOM или нет usable-транскрипта за ~90 мин) → **whisper.cpp** (квантованный large) + pyannote, если веса доступны или качаются с разрешённых хостов.

ffmpeg `afftdn` / highpass **не повторять** — уже проверен и отклонён.

### B. Проверка смысла (обязательна)

- Локально: **Qwen3-8B** (GGUF Q5_K_M предпочтительно; Q4 только если Q5 не влезает в RAM).
- Без диаризации: **2–3 случайных** фрагмента (~2 предложения / 10–20 с).
- С диаризацией: **2–3 фрагмента на каждого спикера**.
- Вопрос модели: «Это связная русская речь совещания или набор правдоподобных, но бессмысленных фраз? Коротко обоснуй.»
- `success` только если большинство фрагментов осмысленны. `rw_ratio` не спасает бессмысленный текст.

### C. Шумодав — только если смысл плохой (макс. 2 библиотеки)

Не ffmpeg. Кандидаты: **DeepFilterNet**, **RNNoise**.

- На библиотеку: дефолт + **не более 2** осмысленных правок параметров. Смотреть, что меняется (смысл, покрытие речи, не «робот»).
- Стоп библиотеки: смысл стал ok, или покрытие речи явно упало, или 3 пресета исчерпаны.
- Если диаризация есть и **один спикер** заметно хуже — гонять шумодав/повтор ASR **только по его таймкодам**, затем склеить.

## Вне скоупа этого этапа

Чанкинг эмбеддингами, саммари, Gemini/NVIDIA ASR, NeMo. API LLM не нужен, если Qwen3-8B запускается.
