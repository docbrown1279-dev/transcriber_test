# Stage 1d — GigaAM v2 RNNT и Whisper Podlodka Turbo

## Результат

На `data/processed/meeting_sample_loudnorm.wav` локально выполнены два ASR-стека без WhisperX:

1. `gigaam` с моделью `v2_rnnt`;
2. `transformers` с `bond005/whisper-podlodka-turbo`.

Оба стека использовали одну и ту же отдельную диаризацию `pyannote/speaker-diarization-3.1`. Получено 413 поворотов речи и 5 спикеров. Два поворота длиннее лимита были разделены, поэтому каждому ASR переданы одинаковые 415 срезов; максимальная длительность среза — 23,051 с. WhisperX, NeMo, Gemini/NVIDIA ASR, Qwen-Omni, шумоподавление, чанкинг и суммаризация не использовались.

`eval/hypothesis.example.json` отсутствует и в текущей базовой ветке, и в актуальном `origin/main`. Поэтому применена явно заданная в задаче форма: `audio`, `language`, `model`, `provider`, `execution_mode`, `segments`, а внутри сегмента — только `id`, `start`, `end`, `speaker`, `text`.

## Подготовка и HF gate

- HF-токен присутствовал; значение не выводилось и не сохранялось.
- Авторизованный GET `pyannote/speaker-diarization-3.1/resolve/main/config.yaml`: HTTP 200.
- Авторизованный GET `pyannote/segmentation-3.0/resolve/main/config.yaml`: HTTP 200.
- Исходный fixture один раз преобразован фильтром `loudnorm=I=-16:TP=-1.5:LRA=11` в mono PCM WAV 16 кГц.
- Длительность WAV: 1468,662 с.
- Диаризация выполнялась локально на CPU 783,848 с; sidecar: `results/asr/pyannote_diarization.json`.
- Два граничных pyannote-поворота после инференса выходили за конец WAV на 0,034 и 0,304 с из-за edge padding; sidecar и гипотезы ограничены фактической длительностью 1468,662 с. Распознаваемые массивы уже были ограничены длиной WAV, поэтому текст не пересчитывался.

Установленные версии: `gigaam 0.1.0`, `faster-whisper 1.2.1`, `pyannote.audio 3.4.0`, `transformers 5.16.1`, `pymorphy3 2.0.6`, `pymorphy3-dicts-ru 2.4.417150.4580142`, `torch 2.5.1`, `numpy 1.26.4`, `scipy 1.16.3`.

При первом запуске pyannote выявились две несовместимости свежих транзитивных зависимостей: удалённый аргумент Hub-клиента `use_auth_token` и ABI ONNX Runtime с NumPy 2.x. Применён локальный адаптер `use_auth_token` → `token`; NumPy закреплён на 1.26.4, SciPy — на совместимой 1.16.3. Модель и метод диаризации не менялись. Это уложилось в лимит двух установочных попыток семейства.

## Словарный gate и interval-only fallback

Для каждого ASR-сегмента токены выделялись по буквам. Метрики:

- `rw_ratio`: известные `pymorphy3` кириллические слова / все буквенные токены;
- `latin_ratio`: латинские токены длиной не менее трёх букв / все буквенные токены;
- цикл: четыре одинаковых соседних токена.

Сегмент проваливал gate при `rw_ratio < 0.85`, `latin_ratio >= 0.08` или цикле. Кандидаты сортировались сначала по убыванию `latin_ratio`, затем по возрастанию `rw_ratio`; на стек применялся лимит 15. Только выбранный интервал с отступом 0,35 с распознавался `faster-whisper large-v3`, CPU int8, `language=ru`, `vad_filter=true`, `condition_on_previous_text=false`. У сегмента заменялся только текст; исходные `id`, полные таймкоды и спикер сохранялись.

## Известные плохие окна

Ни один сегмент в трёх контрольных окнах не попал в первые 15 retry ни у одного стека. Следовательно, изменения ниже относятся к базовым GigaAM/Podlodka на pyannote-срезах, а не к fallback.

### 09:39–09:51

- Stage 1a `medium` содержал испорченный фрагмент `Это наш вопрос.�에.`.
- Stage 1b WhisperX откатывался на длинный английский текст (`staff`, `we are waiting...`).
- GigaAM выдал только русскую речь о количестве квартир и ожидании согласования; английского отката и цикла нет, но одна перекрывающаяся реплика длительностью 0,067 с пуста.
- Podlodka также осталась на русском и передала основной смысл; на короткой реплике есть сомнительное `ЖП`.

### 10:45–10:48

- Stage 1b WhisperX выдавал цикл `staff` семь раз.
- GigaAM: русский текст без цикла, но фраза `где какой то транслятор представился` семантически неточна.
- Podlodka: `Где какой-то ретранслятор, не знаю.` — русский связный вариант без цикла.
- В Stage 1a отдельного сегмента, покрывающего это короткое окно, не было.

### 14:45–15:10

- Stage 1a `medium` давал обрывочные русские фразы.
- Stage 1b WhisperX переходил на английский (`We arose...`, многократное `Yes`) и добавлял `drain`.
- Оба новых стека остаются на русском, без английского отката и многократного цикла. GigaAM передаёт обсуждение мощности трансформаторов, но дробится на пустые/однословные реплики. Podlodka читабельнее, хотя содержит ошибку `масса губолитных характеристик` и короткие обрывы.

Итог по контрольным окнам: английские откаты и циклы Stage 1b устранены уже базовыми моделями при распознавании отдельных pyannote-поворотов.

## Вывод

Оба стека всё ещё нуждаются в `large-v3` retry на отдельных интервалах: после лимита остаётся 149 проблемных сегментов у GigaAM и 45 у Podlodka. Однако массовые отказы GigaAM в основном связаны с пустыми очень короткими поворотами, а Podlodka склонна галлюцинировать на таких поворотах вместо пустого результата.

Для следующего продуктового прототипа из этих двух вариантов предпочтительна Podlodka Turbo + отдельная pyannote: меньше сегментных отказов и лучше связность на контрольных окнах. Interval-only fallback следует сохранить, но до него нужна явно заданная политика для сверхкоротких pyannote-срезов; в Stage 1d такая дополнительная эвристика не добавлялась.

Внешние API не вызывались, аудио никуда не отправлялось.
