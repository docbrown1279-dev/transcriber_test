# Этап 1e — диаризация, табличное объединение и четыре ASR-модели

## Среда и доступ

- CPU: 4 vCPU, RAM: 15 GiB, GPU отсутствует.
- Все четыре заданных клипа найдены; `ffprobe` подтвердил длительности 83/85/85/85 с.
- HF gate пройден до диаризации: gated-файлы `pyannote/speaker-diarization-3.1/config.yaml` и `pyannote/segmentation-3.0/config.yaml` вернули HTTP 200.
- Версии: `pyannote.audio 4.0.7`, `gigaam 0.2.0`, `faster-whisper 1.2.1`, `transformers 5.16.1`, `torch 2.13.0`, `torchaudio 2.11.0`.
- Выполнение только локальное, CPU. Внешние ASR/API не использовались.

## Pyannote и таблица интервалов

- Модель: `pyannote/speaker-diarization-3.1`.
- Диаризация выполнялась на исходных M4A без loudnorm, denoise, Silero VAD и `silencedetect`.
- Сначала соседние интервалы одного спикера с разрывом ≤ 0,3 с объединялись через `min(start)`/`max(end)`. Затем интервалы короче 1,0 с поглощались ближайшим соседом; при равном выборе предпочитался тот же спикер. Аудиофайлы при объединении не создавались.
- Из каждой итоговой строки отдельно извлекался диапазон исходного клипа. Конкатенации, обратной склейки, crossfade и time-stretch не было.

| Клип | Raw turns | Merged rows | С gain | Без gain |
|---|---:|---:|---:|---:|
| `test_voice` | 7 | 4 | 2 | 2 |
| `test_apartments` | 20 | 12 | 8 | 4 |
| `test_transformers` | 16 | 9 | 8 | 1 |
| `test_ninth` | 28 | 16 | 11 | 5 |

Техническое отклонение: при первом запуске inference для `test_voice` завершился, но последующая проверка WAV остановила процесс из-за трёх лишних samples от округления FFmpeg; таблица тогда ещё не была сохранена. После добавления немедленного checkpoint таблицы inference `test_voice` был повторён один раз с той же моделью и настройками. Для остальных трёх клипов был ровно один inference. Итоговые интервалы проверены; длительность каждого extract совпадает с `end - start` с допуском не более двух samples.

## Gain

- Энергия измерялась через `astats` как RMS dBFS; peak использовался только как ограничитель.
- Для RMS ≥ −30 dBFS применялся `gain_db = 0`.
- Для тихих строк использовался линейный `volume=`: `min(-23 - RMS, +18 dB)`, дополнительно ограниченный до peak ≤ −1 dBFS.
- Другие фильтры громкости/динамики не использовались.
- Всего: 29 строк с gain и 12 без gain.

## ASR

Все основные модели читали одни и те же gained WAV. Язык зафиксирован как `ru`; дополнительный VAD не использовался; перенос текста между строками отключён.

| Проход | Модель | Wall time |
|---|---|---:|
| Diarization + extracts | `pyannote/speaker-diarization-3.1` | 153,928 с |
| Gained | GigaAM `v3_rnnt` | 23,575 с |
| Ungained A/B | GigaAM `v3_rnnt` | 19,548 с |
| Gained | `bond005/whisper-podlodka-turbo` | 340,695 с |
| Gained | faster-whisper `large-v3`, CPU int8 | 193,041 с |
| Gained | `bond005/whisper-large-v3-ru-podlodka` | 1461,874 с |

- GigaAM v3 загрузился успешно; fallback `v2_rnnt` не понадобился.
- Строки GigaAM длиннее 25 с делились только по временной оси на последовательные части до 25 с; каждая часть заново извлекалась из исходного клипа.
- Ни в одном клипе peak итоговых строк не достиг −0,1 dBFS, поэтому ungained GigaAM выполнен для всех четырёх клипов. `gigaam_ungained: skipped_clip` отсутствует.
- Podlodka Turbo потребовал внутренние timestamp tokens для строки длиннее 30 с; эти относительные времена отброшены. JSON сохраняет только clip-time границы строки.
- Gold и другие файлы из `eval/` не читались; метрики качества по gold не считались. Полные транскрипты в этот отчёт не копировались.
- Denoise, chunking, WhisperX alignment и LLM summary не выполнялись по условиям этапа 1e.

## Бенчмарк скорости на 25 секундах

- Источник: исходный `data/test_transformers.m4a`, интервал `[0, 25)`; один WAV, 16 кГц mono PCM, ровно 400000 samples.
- Обработка отсутствует: без gain, denoise, диаризации и дополнительного VAD.
- Файлы моделей уже находились в локальном cache после основного прогона.
- Модели запускались последовательно в отдельных процессах. Завершение процесса гарантировало выгрузку модели перед запуском следующей.
- `inference_sec` включает чтение WAV и распознавание, но не загрузку модели. `RTF = inference_sec / 25`.

| Модель | Load, с | Inference, с | Load + inference, с | Process wall, с | RTF |
|---|---:|---:|---:|---:|---:|
| GigaAM `v3_rnnt` | 2,321 | 0,864 | 3,185 | 5,234 | 0,035 |
| `bond005/whisper-podlodka-turbo` | 1,871 | 12,363 | 14,234 | 19,037 | 0,495 |
| faster-whisper `large-v3`, CPU int8 | 7,919 | 6,153 | 14,072 | 16,738 | 0,246 |
| `bond005/whisper-large-v3-ru-podlodka` | 4,469 | 93,288 | 97,757 | 102,895 | 3,732 |

На этом единичном 25-секундном фрагменте GigaAM показал минимальное время inference. Среди Whisper-моделей быстрее всего отработал faster-whisper `large-v3` CPU int8. Это измерение скорости одного запуска, а не статистический performance-тест и не оценка качества распознавания.
