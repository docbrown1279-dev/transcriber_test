Новой разметки нет. Регионы взяты как есть из `results/asr/1f2/ten_vad/` и `results/asr/1f2/fsmn_vad/` (`speech_regions`). Silero не перераспознавался: текст той же семьи срезов — `results/asr/1f/vad_wespeaker/`. `results/asr/1f/`, `results/**/2/` и JSON VAD/эмбеддеров 1f2 не перезаписывались.

## Среда

- `.venv-gigaam` собран заново (снапшот 1f не содержал venv): `gigaam 0.2.0` с `git+https://github.com/salute-developers/GigaAM.git`, `torch 2.13.0+cpu`, `torchaudio 2.11.0+cpu`. CUDA нет.
- `OMP_NUM_THREADS` / `num_threads` = 2. Модель выгружалась между TEN и FSMN (отдельный процесс на каждый id).
- Рецепт ASR = 1f: `prepare_gain_rows` / `extract_clip` / `gigaam.load_model("v3_rnnt", fp16_encoder=False, device="cpu")`. Linear `volume=` только при RMS < −30 dBFS. Регион > 25 с режется только по времени (`test_ninth` FSMN: 13,42–39,15 → 13,42–38,42 + 38,42–39,15). Спикер везде `SPEECH`.
- Установка: одна попытка, успех. Внешнее ASR/API не использовалось, аудио в Gemini/NVIDIA не отправлялось.
